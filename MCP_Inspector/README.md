# MCP Inspector Learning Project

This repository contains my initial implementation of an **MCP Inspector** server, built as part of the [Hugging Face MCP Course](https://huggingface.co/learn/mcp-course).

##  Objective
The goal of this project is to learn the fundamentals of the **Model Context Protocol (MCP)** by building a basic server and using the official **MCP Inspector** tool to test and debug it.

## Learning Source
- **Course:** [Hugging Face MCP Course - Unit 1: SDK](https://huggingface.co/learn/mcp-course/unit1/sdk)
- **Key Concepts:** MCP Architecture, Tools, Resources, Prompts, and the Python/TypeScript SDKs.

## Tech Stack
- **Protocol:** Model Context Protocol (MCP)
- **Language:** Python (using `mcp.server.fastmcp`)
- **Testing Tool:** [MCP Inspector](https://github.com/modelcontextprotocol/inspector)
